# RAM Working Set Trim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add non-destructive RAM cleanup via Win32 working set trim — a global "TRIM RAM" button and a per-selection "TRIM SELECTED" button — to `main.pyw`.

**Architecture:** A module-level `trim_process(pid)` function calls `kernel32.SetProcessWorkingSetSizeEx` to release idle memory pages for a given PID, returning bytes freed. `_trim_all()` runs this across all PIDs in a background thread; `_trim_selected()` runs it on selected tree rows on the main thread. Both update the status bar and RAM bar on completion.

**Tech Stack:** Python 3, tkinter, psutil, ctypes (all already in use)

```python
# ── Working-set trim (Win32) ───────────────────────────────────────────────────
_kernel32 = ctypes.windll.kernel32
PROCESS_SET_QUOTA            = 0x0100
PROCESS_QUERY_INFORMATION    = 0x0400

def trim_process(pid: int) -> int:
    try:
        before = psutil.Process(pid).memory_info().rss
    except (psutil.NoSuchProcess, psutil.AccessDenied):
        return 0
    handle = _kernel32.OpenProcess(
        PROCESS_SET_QUOTA | PROCESS_QUERY_INFORMATION, False, pid)
    if not handle:
        return 0
    try:
        _kernel32.SetProcessWorkingSetSizeEx(handle, -1, -1, 0)
        try:
            after = psutil.Process(pid).memory_info().rss
        except (psutil.NoSuchProcess, psutil.AccessDenied):
            after = before
        return max(0, before - after)
    finally:
        _kernel32.CloseHandle(handle)
```

```python
    def _trim_selected(self):
        sel = self.tree.selection()
        if not sel:
```

### Task 4: Implement `_trim_all`

**Files:**
- Modify: `main.pyw` — add method to `RamBo` class, after `_trim_selected`

- [ ] **Step 1: Add the method**

```python
    def _trim_all(self):
        self.trim_all_btn.config(state=tk.DISABLED, text="TRIMMING...")
        self.status_var.set("Trimming working sets…")

        def _do():
            pids = psutil.pids()
            freed = 0
            count = 0
            for pid in pids:
                result = trim_process(pid)
                if result > 0:
                    freed += result
                    count += 1
            self.after(0, lambda: _done(freed, count))

        def _done(freed, count):
            freed_mb = freed / 1024 ** 2
            self.trim_all_btn.config(state=tk.NORMAL, text="✂  TRIM RAM")
            self.status_var.set(
                f"Trimmed {count} process(es) — freed {freed_mb:.1f} MB")
            self._update_ram()

        threading.Thread(target=_do, daemon=True).start()
```
